## Ghanaian English & Twi/Ga usage

The draft already has a consistent instinct here — worth formalizing so it doesn't drift:

- **Italicize non-English words/phrases on use**, light-touch translate through context rather than footnoting: *Nkonkonsa* (gossip), *Bad Luck Nkoaa* ("just bad luck" — already glossed in-line by the narration, good model to repeat), *Agooo* (a greeting call, used as-is without translation since context carries it)
- **Ghanaian English speech patterns**: sentence-final "eehh," rhetorical questions used as accusations ("So you are now coming eehh?"), reduplication/emphasis through repetition ("Stoooooppppp!!") — keep these for dialogue naturalism, but watch density; a little goes a long way across 27 chapters
- **Currency**: cedis, written as **₵** with the number (₵300, ₵20) — already consistent in the draft
- **Honorifics/address**: "Madam" for the egg seller, driver nicknames ("Charlie") — keep this register for working-class Accra texture; avoid it drifting toward more formal or more caricatured registers in either direction

## Formatting conventions already established — worth keeping consistent

- **Scene breaks**: "• • •" — already used twice in the draft; adopt as the standard scene-break marker throughout rather than switching styles
- **Section/interstitial headers** (e.g., "MORNING NEWS," "WHERE WAS MANSA?," "TRAGEDY"): ✅ **Decided — kept as an intentional pulpy device.** One reconciliation needed with the single-POV decision: several of these headers originally sat over scenes Kwame doesn't witness (the CID search, "WHERE WAS MANSA?"). Recommend repurposing the header style as part of **how information arrives** rather than only as scene dividers — e.g., used inside Ch. 14 to punctuate the beats of Nene's account, or styled like a Kasoa FM bulletin when news reaches Kwame secondhand. This keeps the device without contradicting the POV rule.
- **Emphasis for shouted/emotional dialogue**: elongated spelling ("Whaaaaaaat," "Stoooooppppp!!") and heavy exclamation points. ✅ **Decided — kept as an intentional device.** Recommend reserving it for genuine high-intensity beats (the egg-seller mob, the argument's peak, the arrest) rather than letting it appear in quieter scenes, so it retains its impact rather than becoming a default dialogue tag.
